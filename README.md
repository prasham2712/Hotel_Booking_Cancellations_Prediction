# Hotel Booking Cancellation Prediction

## *Overview*  
This project aims to predict hotel booking cancellations to optimize operations and minimize revenue loss. The analysis involves data preprocessing, feature engineering, and training multiple models like Logistic Regression, Decision Trees, Random Forest, and XGBoost. Key findings are used to make data-driven recommendations for improving hotel resource allocation and customer satisfaction.

## *Key Findings*  
- **Model Performance**: The Random Forest model emerged as the most effective predictor for cancellations, followed by XGBoost with competitive results.
- **Key Features**: Significant factors influencing cancellations include customer type, lead time, deposit type, and market segment.
- **Actionable Insights**: Provides insights for optimizing resource allocation and minimizing financial losses.
